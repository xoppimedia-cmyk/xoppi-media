# Xoppi Media portfolio — GitHub Pages

This folder contains the complete static Xoppi Media portfolio, including all four playable videos. No build tools or coding are required.

## Publish with GitHub Pages

1. Sign in to GitHub and create a new **public** repository named `xoppi-media`.
2. Open the repository and choose **Add file → Upload files**.
3. Upload the **contents of this folder**, not the ZIP file itself. Make sure `index.html` appears at the top level of the repository.
4. Commit the uploaded files to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select the `main` branch and `/(root)`, then click **Save**.
8. Wait a few minutes and click **Visit site** on the same Pages settings screen.

The address will normally be:

`https://YOUR-GITHUB-USERNAME.github.io/xoppi-media/`

## Important

- Keep the folders and filenames exactly as they are.
- Do not move `index.html` into another folder.
- The `.nojekyll` file is intentionally empty and should remain in the repository.
- GitHub Pages sites are public. The portfolio does not contain passwords or private keys.
- To update the portfolio later, replace the changed files in the repository and commit them. GitHub Pages will republish automatically.

## Optional custom domain

After purchasing a domain, open **Settings → Pages → Custom domain**, enter the domain, and follow GitHub's DNS instructions.
